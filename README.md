# Data Structure Graph Analyzer

## 1. Project Overview

Data Structure Graph Analyzer is a Java console-based application developed as a group assignment for the Data Structures and Algorithms module.

The project demonstrates the implementation and use of different data structures and searching algorithms. Users can interact with the program through a menu and perform different operations.

## 2. Technologies Used

- Programming Language: Java
- IDE: Eclipse & VS Code
- Version Control: Git and GitHub

## 3. Main Features

### Array Operations
- Display array elements
- Insert and delete elements
- Reverse an array
- Find the maximum and minimum values
- Calculate the sum of array elements

### Searching Algorithms
- Linear Search
- Binary Search

### Stack Operations
- Push elements
- Pop elements
- View the top element
- Display stack elements
- Check whether the stack is empty or full

### Queue Operations
- Enqueue elements
- Dequeue elements
- View the front element
- Display queue elements
- Check whether the queue is empty or full

### Linked List
- Implementation of a linked list using nodes

### Graph Operations
- Represent graph vertices and connections
- Add and remove vertices and edges
- Display the graph
- Search for vertices
- Perform Breadth-First Search (BFS)
- Perform Depth-First Search (DFS)

### Performance Comparison
- Compare Linear Search and Binary Search
- Test different array sizes
- Measure average execution time
- Display the results in the console
