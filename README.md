Linked List Implementation
Overview

This project implements a Singly Linked List using Java. A linked list stores data in nodes, where each node contains a value and a reference to the next node.

Features
Insert: Add elements to the linked list.
Display: Display all elements in the list.
Search: Search for a specific value.
Delete: Remove a specified value from the list.
Files
Node.java – Defines a node containing data and a reference to the next node.
LinkedList.java – Implements linked list operations.
TestLinkedList.java – Tests the linked list functionality.
Example Output
Linked List: 10 -> 20 -> 30 -> NULL
Searching for 20...
20 found.
20 deleted.
Linked List: 10 -> 30 -> NULL
Technologies Used
Java
Object-Oriented Programming
Singly Linked List Data Structure
How to Run

Compile the Java files:

javac Node.java LinkedList.java TestLinkedList.java

Run the test program:

java TestLinkedList
